# Архитектура

## Компоненты

### 1. VK Long Poll (vk-api)

Бот подключается к сообществу ВКонтакте через Long Poll API и получает события
`MESSAGE_NEW`. На каждое входящее сообщение извлекаются `from_id`,
`peer_id` и `text`.

### 2. SupportAssistant (gigachat.py)

Класс-обёртка над GigaChat API (`GigaChat-2-Max`):

- хранит историю диалога в оперативной памяти (сессия на `user_id`);
- ограничивает историю до `MAX_CONTEXT_MESSAGES` (20) сообщений;
- отправляет в запрос последние `LAST_N_MESSAGES` (10) сообщений;
- формирует системный промпт вместе с базой знаний (`knowledge.py`);
- возвращает фиксированный fallback-ответ при ошибке GigaChat.

### 3. База знаний (knowledge.py)

Статичные текстовые блоки:

- `ZEROCODER_INFO` — информация об университете и контакты;
- `COURSES_INFO` — актуальные программы обучения;
- `FAQ_INFO` — ответы на частые вопросы.

База знаний добавляется к системному промпту, поэтому модель не обязана
хранить факты — она отвечает строго по предоставленным данным.

### 4. Конфигурация (config.py)

Читает `.env` через `python-dotenv`, валидирует обязательные переменные
`VK_TOKEN`, `VK_GROUP_ID`, `GIGACHAT_CREDENTIALS`.

## Поток сообщения

```
Пользователь → ВКонтакте → Long Poll → bot.py
                                        │
                                        ▼
                              SupportAssistant.get_response()
                                        │
                         ┌──────────────┴───────────────┐
                         ▼                              ▼
                history (сессия)              GigaChat API (REST)
                         │                              │
                         └──────────────▶ ответ ◀──────┘
                                        │
                                        ▼
                        messages.send → ВКонтакте → Пользователь
```

## Ограничения

- История диалогов хранится в памяти процесса и теряется при перезапуске.
- Для масштабирования рекомендуется вынести сессии в Redis или БД
  (см. ветку `feature/session-memory-optimization`).
